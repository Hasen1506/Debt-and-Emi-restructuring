# Security policy

Found a security problem in RightDue (https://rightdue.app)? Email
**security@rightdue.app** with "Security" in the subject. Please don't open a
public issue for it, and don't access other people's data or send automated
traffic beyond what proves the problem. We reply within 7 days and credit you
if you'd like. See also https://rightdue.app/.well-known/security.txt.
